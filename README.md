# Protocollo Inglese

App web installabile (PWA) per tenere traccia dell'ascolto quotidiano in inglese: obiettivo del giorno, minuti a passi da 5, ripasso delle parole a intervalli, prossimi podcast.

Il codice è qui; i dati stanno in un repository privato a parte e l'app li legge con una chiave salvata solo sul dispositivo.
